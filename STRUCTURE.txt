API Endpoints
=============

Authentication (/auth)
├── POST   /auth/register         Create new user
├── POST   /auth/login            Authenticate user
└── GET    /auth/me               Get current user

Friends (/friends)
├── GET    /friends                List all friends
└── POST   /friends                Add a friend

Expenses (/expenses)
├── GET    /expenses/{friend_id}           Get expenses with friend
├── POST   /expenses                       Create new expense
└── GET    /expenses/{friend_id}/balance   Get balance

Utility
├── GET    /                      API info
├── GET    /health                Health check
├── GET    /docs                  Swagger UI
└── GET    /redoc                 ReDoc


Database Schema
===============

Users Table
├── id (UUID, PK)
├── email (unique, indexed)
├── password_hash
├── name (optional)
└── created_at

Friends Table
├── id (UUID, PK)
├── user_id (FK → users.id, indexed)
├── friend_id (FK → users.id, indexed)
├── created_at
└── UNIQUE(user_id, friend_id)

Expenses Table
├── id (UUID, PK)
├── user_a_id (FK → users.id, indexed)
├── user_b_id (FK → users.id, indexed)
├── amount (decimal)
├── description
├── paid_by_user_id (FK → users.id, indexed)
├── expense_date
├── created_at
├── updated_at
└── CHECK(paid_by_user_id IN (user_a_id, user_b_id))

Quick Start
===========

1. ./setup.sh                     # Setup environment
2. Edit .env file                 # Configure database
3. createdb expense_tracker       # Create database
4. ./migrate.sh                   # Run migrations
5. ./run_server.sh                # Start server
6. Visit http://127.0.0.1:8000/docs


Technology Stack
================

• Framework: FastAPI 0.104.1
• Server: Uvicorn with hot reload
• Database: PostgreSQL
• ORM: SQLAlchemy 2.0.23
• Migrations: Alembic 1.12.1
• Auth: JWT (python-jose) + Bcrypt (passlib)
• Validation: Pydantic 2.5.0
• Environment: python-dotenv
